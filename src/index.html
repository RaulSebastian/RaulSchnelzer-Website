Who I am

About

Hi, I'm Raul!

I am a creativity-driven and passionate developer who aspires towards better software solutions. I thrive on challenge and constantly set goals for myself to improve my knowledge, soft-skills, learning new methodologies and technologies.

As such I read books (yes, the physical ones), use on-demand technology courses, read blogs and am active on networks like StackOverflow.

Origins I began my journey in web development at 13, creating HTML and JavaScript pages for a gaming clan. As a self-taught developer, I learned through hands-on experimentation, picking up tools like Photoshop, Premiere, PHP, and Flash to build highly animated web experiences.

By 15, I built my first professional website for a doctor’s office, marking my transition into real-world projects. Around the same time, I developed custom Warcraft 3 maps using JASS scripting, which introduced me to core programming concepts.
